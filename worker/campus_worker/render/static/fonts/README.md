# Fonts

Self-hosted variable fonts under the SIL Open Font License 1.1 (license texts alongside):

- **Source Serif 4** (Adobe; optical-size + weight axes) — display headlines (opsz ≥ 36) and article text.
- **Source Sans 3** (Adobe; weight axis) — navigation, labels, tables, tool controls.

Obtained from the google/fonts repository (ofl/sourceserif4, ofl/sourcesans3) and converted to WOFF2 with fontTools.
`font-display: swap` with size-adjusted local fallbacks (Georgia / system-ui) limits layout shift.

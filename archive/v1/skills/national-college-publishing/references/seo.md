# SEO (role I)
URL model (`seo.classify_url`): `/schools/{school}/`, `/schools/{school}/{topic}/`, `/schools/{school}/{topic}/{entity}/`, `/schools/{school}/{topic}/compare/{a}-vs-{b}/`, `/tools/{tool}/`, `/about/{policy}/`. Trailing slash, lowercase. Any query string (filters, sorts, calculator state, search) is noindex with canonical to the clean path. Staging is noindex,nofollow and robots-disallowed.
Titles/descriptions from the real headline/deck (`seo.title_and_description`); year only when maintained. Structured data must match visible content (`seo.validate_structured_data`): Organization/desk author, real dates, no review/FAQ/HowTo markup without eligible visible content. Sitemap lists only published, passed, non-redirected pages. Links: no orphans, no links to redirected paths (`seo.check_internal_links`). Observation windows before any title change; one factor per experiment (`experiments`).

# Maintenance and analysis (role L)
Hourly: `cli run-once` (reclaim leases, dispatch within budget/quota, heartbeat). Daily: `scheduler.plan_daily` (due sources with the exploration share for underserved schools), material-change propagation, exception digest. Weekly: duplicate coverage, source reliability, costs per accepted page / verified update, experiment review.
Source change → `propagation.on_claim_changed` flags pages and enqueues `revalidate_page` (idempotent). Zero-fact regression guard halts propagation and raises a critical exception instead of blanking pages. Corrections: material error → correction, dependent-page inspection, dated note; never a silent change behind an old verified date. Backups: `scripts/backup.sh` daily target; `scripts/restore_test.sh` proves restore. Held/dead-letter queue has owner, reason, retry condition, age (dashboard).

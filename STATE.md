- Start pages are one per reader, shared by the topics (spec §4): plan.py queues a second topic's path for an existing page (the planner and the reader-map session see the existing keys), write.py adds the topic's "Read in this order / Tools / Dates to watch: <Topic>" sections in place, check.py scopes the check to that topic's sections. `plan.sh <topic> --sync` queues plan edits without a session. publish.sh: lint failures go to the image step or the writer (up to three rounds), transient link errors wait, a source that fails on two passes goes to a writer round, only duplicates reject.

## Headline contradictions and flags
1. Notice before lease renewal in the City: 60 days (pre-2022) -> 180-day draft -> 120 days adopted April 2022 per WSKG; code text unread. Cornell Law guide (Feb 2026) does not mention it. See file 09.
2. Certificate of Compliance scope: city COC page says 3+ unit buildings or units with 6+ unrelated people (3-year validity; frats/sororities/dorms 1 year); city Housing Inspections page says inspections are required for all residential rental dwellings; an older-code search summary said 1-2 family every 5 years. Unresolved. File 08.
3. Building Division phone: 607-274-6508 (COC page, Cornell, Cornell Law), 607-274-6510 (main page), 6509 or 6510 (Housing Inspections). File 08.
4. City domain moved from cityofithaca.org to cityofithacany.gov; Cornell pages link the old one.
5. Cornell's second-year qualified housing page says "for 2026-2027" but lists 2024-25/2025 deadlines (Dec 23, 2024 etc.). File 01.
6. Cornell neighborhoods page repeats identical paragraphs for several neighborhoods; walk times are Cornell estimates. File 01.
7. TCAT: the Cornell Transportation page says after-6pm weekday and weekend free rides for non-first-year degree students, OmniRide $200/yr, PhD students and graduate assistants free pass; Cornell International Services page only says first-years get the pass. Student Assembly resolution (March 2026, unread) asks Cornell to fund more. File 05.
8. Cornell budget lines ($13,744 housing and $7,604 food, 2025-26) are on-campus budget lines, not an off-campus rent number. 2026-27 undergrad figures not visible. Grad 2026-27 NYC subtotal does not add up. File 07.
9. Cornell undergrad aid: security deposits, first/last month's rent, rent in unregistered months are not covered by aid. File 07.

# Lane D: The competition, Transferring to Cornell

Topic: Transferring to Cornell (Cornell University, Ithaca NY; NOT Cornell College, Iowa). Lane: competition. Checked 2026-11-11.

Method notes
- intel/transfer/raw/demand-questions.md has a header and no rows (read 2026-11-11), so the question list comes from my own searches of what students and parents ask, plus the titles of the 17 transfer articles in Cornell's admissions FAQ (faq.enrollment.cornell.edu).
- "Top results" are the order WebSearch returned on 2026-11-11 (US, not personalized, not a rank tracker; order is indicative only). Publication dates are recorded only where the result or page shows one. Several result pages were seen only as titles and URLs in the search results (marked "not shown" or "snippet"); the pages I actually opened are listed in the Pages read table at the end.
- Where a number comes from a third-party site it is marked third-party and unverified.
- Forum posters (Reddit, CollegeVine FAQ, College Confidential) are voice only, never a fact source.
- Many "Cornell transfer ..." results are about Cornell College (Iowa), a different school. This ambiguity is itself a finding.
- Tool note: the Edit tool was disabled in this session, so the file was saved by rewriting it whole at each checkpoint (two checkpoints before this final version). The Common Data Set PDF could not be decoded by the fetch tool (binary) and pdftoppm is not installed, so CDS transfer numbers were NOT read.
- Source checklist (Phase 1b): this topic is not crime, voting, tenant law or local rules, so those lists were not the main target. The Cornell policy list was used (specific Cornell office pages, current-year PDFs, Cornell Chronicle). Tenant-law pages were not searched in this lane (Q29 off-campus note points to the Cornell housing search checklist only): recorded as not searched.

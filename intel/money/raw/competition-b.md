# Lane D part B: per-question SERP notes (Q1 to Q28), written 2026-11-08

How this was made, honestly: for each demand question I ran the primary query through the search tool (one query each). The tool returns a link list plus a short summary, not a dated top-5 table, so "date" is the date in the URL or the page's own date where visible, otherwise "not shown". Rank order below is the order the tool returned them, and for Q1 to Q28 the queue's own top-5 (from demand-questions.md) is the reference list. Page text was NOT opened for most competitor pages in this pass; "says" lines come from the search summary and are marked (summary). Pages I opened myself are marked (read) and are in part C. Checked: 2026-11-08 for all rows.

"TYPICAL AI ANSWER" blocks are my own simulation of a general-knowledge LLM answer, not a source. They are labelled so they never get mistaken for facts.

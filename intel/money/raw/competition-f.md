Why this matters for the competition: the top-ranked "cheap used textbooks" page (https://www.cornellstore.com/course-materials-affordability-efforts) mentions CAMP only as a "subscription based" program with no price, no opt-out date. This is a money-moving fact tied to a date, so it is a strong gap.

# Ad operations (role K)
Adapter `adapters.ads.AdSenseAdapter`: enabled only when the flag is on, a valid publisher id exists, and the environment is production; staging never emits ads. One loader, only after consent. Approved placements by template: guide after essentials (+ between sections when ≥4 sections); profile after facts (+ desktop sidebar); hubs between groups; comparison below results; tools, home and policies none. `ads.txt` from the publisher id.
Ad ops may: configure slots, run one layout experiment at a time with guardrails (task completion, CLS, complaints), import network reports (`revenue.import_adsense_report`). Ad ops may not: inject scripts, change facts/ratings/order, click ads, invent impressions, refresh ads, add interstitials, or claim approval that the account does not show.
Metrics are separate by denominator (`revenue.Metrics`): page RPM per 1,000 pageviews, impression RPM per 1,000 impressions, session revenue per session. Scenario ≠ forecast.

Add/Drop Enrollment Request Form
The
Electronic Student Add/Drop Enrollment Request Form
(2024-2025) (Form will ONLY be available during Add/Drop period)
Should only be used for enrollment changes if you are unable to submit the request online through Student Center.
Each
College Registrar's Office
has specific instructions on how to submit time conflicts, permission codes, course petitioning, or enrollment changes after the deadline. Contact the office for further details.
If you have a permission code that allows you to add or drop the class in Student Center, you do not need to use this form.

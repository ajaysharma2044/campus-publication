# Gold set

The gold set is a small number of pages the owner has approved as the EduExplained standard. They teach the voice faster than any rule, and they are the benchmark every new page is compared against.

## Approved examples
| File | Mode | What it models |
|---|---|---|
| `examples/feature-pillar.md` | feature | "Where Cornell Sleeps": a scene-led pillar with a nut graf, a story spine, named specifics, history and current events, our own math, fair trade-offs, reporting-style attribution, tables for reference, and a calendar and checklist at the end |

Answer-mode examples (a deadline, a fee, a how-to) will be added once written and approved. Until then, answer-mode pages follow `eduexplained-voice` and its before-and-after reference, but take their texture from the feature example: real names, reporting-style attribution, prose over templates.

## Using it
- Read the example for your mode before writing, editing or planning a page. Read the annotations first, then the full text.
- Copy the qualities, not the content or sentences.
- Where the gold set and a rule in `eduexplained-voice` seem to differ, follow the gold set and note the difference in your output so the rule can be fixed.

# Cut list

| Cut | Example | Keep instead |
|---|---|---|
| Restated fact | "$1.50" for the 13th time | The main statement and one reference |
| Reader block restating general facts | TCAT free hours inside four different blocks | Only what changes for that reader |
| Announcements | "Here is what you need to know." "Below, we explain..." | Start with the information |
| Research narration | "per Ithaca Renting's listings read on Nov 8" | The linked fact |
| Process talk | "by our arithmetic", "we could not confirm" | The math with inputs; a plain gap sentence |
| Hedge stacks | "may potentially", "generally tends to" | A flat statement, or one condition stated exactly |
| "Not confirmed:" labels | "Not confirmed: the tax rate." | "The tax rate isn't posted; the app shows it at checkout." |
| Negative openings | "Nobody publishes a list..." | What the reader can do |
| Planner notes | "The pages that rank are from 2023." | Reader-facing advice, or nothing |
| Trivia | trip counts from 2023 | Delete unless it changes a decision |
| Time-bound phrasing | "this week" | A date |
| "Hypothetical" | "a hypothetical junior" | "Say you live in Collegetown and..." |
| Duplicate FAQ | an FAQ question the body answered | Delete the FAQ entry |
